pm2**，开机自启 + 崩溃 3 秒重拉，常驻 17MB）+ nginx `location ^~ /mall-api/` 反代（挂在 **80** 的 lexy-official-site 上，443 的 catch-all 会自动转回来，等于白拿 HTTPS）。小程序端 `utils/constants.js` 新增 `server` 档 = `https://14.103.50.137/mall-api`（**模拟器与真机通用，不用改 IP、不用同 WiFi**），图片由 `resolveAssets()` 拼成 `BASE_URL + /uploads/...`，与 nginx 的前缀替换语义刚好对上。**踩了三个坑，都值得记住**：① 打包时按「后端零依赖、只拷 `server/`」来做是**错的** —— `server/lib/seed.js` 在**模块加载期**就 `require("../../miniprogram/mock/data")`，只拷 server/ 会让进程起来即 `MODULE_NOT_FOUND` 退出；更坑的是 `journalctl -u lexy-mall` **看不到**应用报错（stdout 被 `StandardOutput=append:` 重定向到 `/var/log/lexy-mall.log`），排查第一步必须看那个日志文件。② `setup-server.sh` 原写法是「Node 版本 != 期望值就重装」，而目标机 `/usr/local/bin/node` 是指向 `/opt/node-v22.14.0` 的**符号链接**且同机还有别的 Node 服务 —— 照原样跑会把它覆盖成真实文件，属于「为了装自己的东西改坏别人在用的运行时」，已改成**只判断有没有、有就复用**。③ 用 `ssh host 'bash -s' <<EOF` 去跑 `certbot` 这类会读 stdin 的命令，子进程会把**剩余脚本整段吃掉**（现象：输出莫名截断、后续命令没执行）——这类命令必须单独发一次并加 `</dev/null`。**安全（本轮最关键的一环）**：`NODE_ENV=production` + `DEBUG_PAGE=off`，实测 `/admin`、`/console`、`/debug`、`/preview` 与 `/api/admin/*`、`/api/decorate/*`、`/api/media/*` 在公网**全部 403**（`/mall-api/admin` 是后端 403 + 站点根 `/admin` 是 nginx 410，两处都验，防「只是 nginx 顺手挡了」的假安全）。`.env` 由脚本生成随机 32 字节 `JWT_SECRET`（chmod 600），`ALLOW_MOCK_PAY=1` 保留模拟支付以便手机端跑完整下单链路。冒烟 `.tooling/probe-deployed.mjs` **30/30**（连通 / 管理页面被拒 / 登录 / 首页 / 商品 / 分类 / **加购→下单→核对库存扣减→取消→核对回滚** / 图片静态资源），订单号 `LEXY202610090943161126`、金额 ¥6999、库存 99→98→99 全程核对。既有业务部署前后对照**零变化**（quality-platform 200 / kingclean-public-test 200 / kingclean-preview 302 / stopwatch health 200 / 原 `/api/health` 仍 410）。冒烟产生的联调数据已按用户偏好清空（`db.json` 移除后全新自举，仅留 `catalog.json` + `uploads/`）。遗留：仍是 IP + HTTPS 无域名（开发者工具需关域名校验、真机需开「开发调试」，正式提审必须换已备案域名）；未配 `WX_APPID`/`WX_SECRET` ## 二、技术栈

| 维度    | 结论                                                      |
| ----- | ------------------------------------------------------- |
| 前端框架  | 微信原生开发                                                  |
| 后端方案  | 自建后端（云服务器 + HTTPS + 备案域名），可直连中台/ERP                     |
| 商品数据源 | 自建独立商品库，预留中台对接位                                         |
| 数据库   | MySQL（业务数据）+ Redis（库存锁 / 会话 / 缓存）                       |
| 基础库适配 | 需在开发时确认目标基础库版本；`lazyCodeLoading` 等配置有最低版本要求，**以官方文档核实** |
| 工具链   | 微信开发者工具 + VS Code                                       |
| 数据层现状 | `ENV = mock`，接口契约已固定，真实后端就绪后改一个常量即可切换                   |

**代码安全约定（强制）**

- `AppSecret` / 支付商户密钥 / JWT 密钥：**只存服务端环境变量**，前端零明文，不进 git
- 下单金额一律以服务端报价为准，前端传值仅作展示
- 支付回调必须验签 + 幂等
