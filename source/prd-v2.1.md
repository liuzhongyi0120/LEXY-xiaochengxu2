> 版本 V2.1（小程序真实拆解 · 名称更正版）｜2026-10-07｜莱克电气 品牌部

## 一、产品概述

### （一）产品背景与形态
LEXY莱克官方旗舰店小程序（AppID wx6bc687ff89875e20）是莱克电气在微信生态内的品牌自有电商小程序，技术形态为**基于有赞（Youzan）零售 SaaS 模板开发的独立小程序**（有赞店铺 kdtId=44375018，连锁店铺模式 isChainStore=true），并非微信官方小店。

实测依据：程序包内 `app-config.json` 的 ext 字段包含 `appId / kdtId / isChainStore / shopAppType / themeType / env` 等有赞配置项；代码库含 `@vant`、`@y`、`@y-open` 等有赞组件命名空间，以及有赞零售模板专有分包（`packages/retail`、`packages/retail-shelf`、`packages/salesman`、`packages/guide`）。

线上版本：3.179.7.101（本地缓存包版本号 61）。

### （二）与「微信小店」的关系澄清
本小程序与微信小店（store.weixin.qq.com，AppID wxdf3386d65fd78506）是**两套独立产品**：

| 维度 | 本小程序（LEXY莱克官方旗舰店） | 微信小店 |
|---|---|---|
| 形态 | 品牌自建小程序（有赞 SaaS 底座） | 微信官方交易组件 |
| AppID | wx6bc687ff89875e20 | wxdf3386d65fd78506 |
| 页面与功能 | 自研/模板 452 个页面，功能可深度定制 | 平台托管的标准化交易页 |
| 后台 | 有赞商家后台 + 微信小程序后台 | 微信小店后台 |
| 交易通道 | 有赞交易链路 + 微信支付 | 微信小店官方交易链路 |

两者可并存：小程序承接品牌私域与门店场景，微信小店承接视频号/平台流量成交。

### （三）产品定位
**一句话定位**：LEXY莱克官方旗舰店是莱克电气品牌在微信生态的官方自营商城，覆盖「家用清洁电器 + 净饮水 + 耗材配件」的销售、会员运营与门店服务。

**经营模式**：连锁门店模式（支持多门店/门店自提/扫码购）+ 品牌自营 + 分销员导购体系。

### （四）产品目标
| 目标层级 | 目标描述 | 衡量指标 |
|---|---|---|
| 业务目标 | 承接视频号直播、内容与广告流量的私域成交 | GMV、支付转化率、客单价 |
| 用户目标 | 一站完成整机选购、耗材复购、会员权益领取 | 复购率、会员数、7 日留存 |
| 门店目标 | 打通线上商城与线下连锁门店（自提/扫码购） | 门店订单占比、自提核销率 |
| 品牌目标 | 沉淀品牌私域阵地与会员资产 | 会员开卡数、企微/导购承接量 |

## 二、用户与场景分析

### （一）目标用户
| 用户群 | 特征 | 核心诉求 |
|---|---|---|
| 品牌会员/老客 | 已购整机（洗地机、净水器、除螨仪等） | 耗材复购、会员价、积分兑换 |
| 直播与内容受众 | 从视频号短视频/直播间进入 | 边看边买、直播专享价 |
| 广告引流用户 | 从朋友圈/腾讯广告点击进入 | 快速了解并下单主推款 |
| 连锁门店顾客 | 到店体验后扫码或线上搜索门店 | 门店库存、门店自提、到店服务 |
| 分销员/导购 | 门店导购、员工、外部推广者 | 分享素材、佣金结算、业绩看板 |

### （二）核心使用场景
1. **直播转化**：视频号直播间购物袋 → 小程序商品页 → 下单支付（挂载微信官方直播插件）。
2. **耗材周期复购**：老客从「我的」进入订单/会员中心，通过耗材分组与积分商城完成复购。
3. **会员权益运营**：开卡 → 等级成长 → 会员价与专属券 → 权益卡（礼品卡/储值卡）使用。
4. **门店 O2O**：定位最近门店 → 门店货架浏览/扫码购 → 门店自提或同城配送。
5. **分销裂变**：导购/分销员分享商品或素材 → 好友下单 → 佣金与业绩统计。
6. **积分与任务**：签到/打卡/任务中心赚积分 → 积分商城兑换商品或优惠券。

### （一）总体功能架构
```

├── 首页（自定义 tabBar：首页 / 购物车 / 我的）

├── 积分体系（积分中心 / 积分商城 / 积分流水 / 积分规则 / 签到 / 打卡任务）

├── 门店体系（多门店选择 / 连锁门店 / 门店货架 / 扫码购 / 自提）
└── 直播与视频号（微信直播插件 / 视频号带货 / 短视频）
```
