# 品牌小程序商城 功能清单 PRD

版本 V1.0　｜　2026-10-07　｜　莱克电气 品牌部

定位：品牌自营商城 + 会员营销

编制依据：LEXY莱克官方旗舰店小程序逆向拆解（V2.1 全量版）删减提炼

## 一、文档说明

### 1.1 编制目的

本清单用于新建品牌小程序商城的需求评审与开发报价，是可直接交付研发与外部供应商的功能边界文档。本版在原始拆解版（43 条需求、10 大业务域、452 个页面）基础上，按「品牌自营商城 + 会员营销」的实际经营需要做了大幅删减，最终收敛为 33 条功能、7 个模块。

### 1.2 优先级定义

| 优先级 | 含义 | 判定标准 |
|---|---|---|
| P0 | 一期必做 | 缺失即交易链路中断，商城无法开张 |
| P1 | 二期建议 | 影响转化与复购，是会员营销的核心抓手 |
| P2 | 三期可选 | 体验增强或低频玩法，可按预算后置 |

### 1.3 本版删减范围

相对 V2.1 全量拆解版，本版的取舍如下：

| 原模块 | 处理 | 原因 |
|---|---|---|
| 首页装修、商品、购物车、交易支付、订单售后 | 保留（精简条目） | 商城交易主干 |
| 会员卡、等级权益、权益卡礼品卡 | 保留 | 会员营销核心 |
| 优惠券、积分商城、签到任务 | 保留 | 会员营销核心 |
| 拼团、砍价助力 | 保留（定为 P1） | 拉新裂变需要 |
| 连锁门店、门店货架、门店自提、扫码购 | 删除 | 本期不做线下 O2O |
| 分销员、导购工作台、社区团购 | 删除 | 无分销体系 |
| 小程序直播、视频号带货 | 删除 | 直播走独立直播间，商城不做挂载 |
| 抽奖、盲盒、摇一摇、集卡、预约报名 | 降为 P2 可选 | 低频玩法，按需保留 |
| 有赞 SaaS 底座、分包体积、加密解密等技术细节 | 删除 | 属拆解过程数据，非需求 |
| 模板自带但未启用模块（教育、酒店、品酒会等） | 删除 | 与自身业务无关 |

## 二、产品定位与目标

### 2.1 产品定位

品牌官方自营小程序商城，覆盖「整机销售 + 耗材复购 + 会员运营」的完整闭环。

### 2.2 产品目标

| 目标层级 | 目标描述 | 衡量指标 |
|---|---|---|
| 业务目标 | 承接投放、内容与私域流量的直接成交 | GMV、支付转化率、客单价 |
| 用户目标 | 一站完成选购、复购、会员权益领取 | 复购率、会员数、7 日留存 |
| 品牌目标 | 沉淀品牌私域阵地与会员资产 | 会员开卡数、私域留存 |

### 2.3 核心用户与场景

| 用户群 | 核心诉求 | 对应场景 |
|---|---|---|
| 品牌会员 / 老客 | 耗材复购、会员价、积分兑换 | 从「我的」进订单与积分商城复购 |
| 广告与内容引流用户 | 快速了解并下单主推款 | 落地页 → 商品详情 → 下单 |
| 新客 / 泛人群 | 领券试买、拼团低价 | 领券中心 → 拼团下单 |

## 四、功能清单详表

| HM-02 | 搜索入口 | 搜索框、热门搜索词推荐、历史记录；支持商品名与关键词搜索，结果页可排序筛选 | P0 |
| HM-03 | 商品分组货架 | 自定义商品分组（主推款、耗材专区、配件等）与组内排序，Tab 切换浏览 | P0 |

## 五、非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 高频链路做分包预加载（购物车、下单、支付结果、个人中心）；首页依赖远程装修数据，需骨架屏与加载失败兜底 |
| 包体管理 | 主包与单个分包均需控制在微信平台上限内；新增功能优先落入既有分包，避免主包膨胀 |
| 隐私合规 | 若使用定位能力须在隐私协议中明示并前置授权；按《个人信息保护法》与微信隐私接口规范留存授权记录 |
| 安全风控 | 支付走微信支付官方通道；会员、积分、券等资产类数据须服务端校验；签到、领券、抽奖接口需限频防刷 |
| 可运营性 | 首页装修、活动、优惠券、会员权益均需后台可配置，配置变更不触发小程序重新发版 |
| 稳定性 | 下单、支付、退款关键链路需具备异常兜底与订单状态补偿机制 |

## 六、分期建设建议

| 阶段 | 建设内容 | 目标 |
|---|---|---|
| 一期（MVP） | 全部 14 条 P0 功能 | 商城可开张交易，完成「选品 → 下单 → 支付 → 售后」闭环 |
| 二期 | 全部 13 条 P1 功能 | 会员营销体系上线，拉动复购与裂变 |
| 三期 | 6 条 P2 功能按需选做 | 体验增强与补充玩法 |

## 七、待确认事项

1. 商城技术方案：自研、第三方 SaaS（如有赞、微盟）或混合模式，决定后台可配置能力的边界。
2. 会员体系与现有 CRM、企业微信是否打通，会员资产的归属与同步方式。
3. 积分与订单数据是否需与线下门店或其他渠道打通；本期虽不做门店 O2O，但数据口径需预留。
4. 商品数据源（ERP 或中台）与库存同步方式。
