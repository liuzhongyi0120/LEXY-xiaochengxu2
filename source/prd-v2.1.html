一、产品概述

本章界定产品的技术形态、与微信生态其他交易阵地的关系、产品定位与目标。

（一）产品背景与形态

LEXY莱克官方旗舰店小程序是莱克电气在微信生态内的官方自营商城，承载家用清洁电器（洗地机、吸尘器、除螨仪）、净饮水（碧云泉）及原厂耗材配件的销售与服务。

实测该小程序为基于有赞零售 SaaS 模板开发的独立小程序：程序包内 app-config.json 的 ext 字段包含 appId、kdtId（44375018）、isChainStore（true）、shopAppType、themeType、env 等有赞配置项；代码库含 @vant、@y、@y-open 等有赞组件命名空间，以及有赞零售模板专有分包（packages/retail、packages/retail-shelf、packages/salesman、packages/guide）。

（二）与「微信小店」的关系澄清

本小程序与微信小店是两套独立产品，此前拆解对象有误，特此澄清：

维度LEXY莱克官方旗舰店小程序（本文档对象）微信小店
形态品牌自建小程序（有赞 SaaS 底座）微信官方交易组件
AppIDwx6bc687ff89875e20wxdf3386d65fd78506
功能自由度高，452 个页面可深度定制低，平台托管标准化交易页
后台有赞商家后台 + 微信小程序后台微信小店后台
交易通道有赞交易链路 + 微信支付微信小店官方交易链路

  两者可并存分工：小程序承接品牌私域、会员资产与线下连锁门店场景；微信小店承接视频号与平台侧流量成交。

（三）产品定位

一句话定位：LEXY莱克官方旗舰店是莱克电气品牌在微信生态的官方自营商城，覆盖「清洁电器 + 净饮水 + 耗材配件」的销售、会员运营与门店服务。

经营模式：连锁门店模式（支持多门店、门店自提、扫码购）+ 品牌自营 + 分销员与导购体系。

（四）产品目标

目标层级目标描述衡量指标
业务目标承接视频号直播、内容与广告流量的私域成交GMV、支付转化率、客单价
用户目标一站完成整机选购、耗材复购与会员权益领取复购率、会员开卡数、7 日留存
门店目标打通线上商城与线下连锁门店场景门店订单占比、自提核销率
品牌目标沉淀品牌私域阵地与会员资产会员数、导购企微承接量

二、用户与场景分析

本章按来源与购买动机划分目标用户，并归纳六类核心使用场景。

（一）目标用户

用户群特征核心诉求
品牌会员 / 老客已购整机（洗地机、净水器、除螨仪等）耗材复购、会员价、积分兑换
直播与内容受众从视频号短视频或直播间进入边看边买、直播专享价
广告引流用户从朋友圈 / 腾讯广告点击进入快速了解主推款并下单
连锁门店顾客到店体验后扫码或线上查门店门店库存、门店自提、到店服务
分销员 / 导购门店导购、内部员工、外部推广者分享素材、佣金结算、业绩看板

（二）核心使用场景

1. 直播转化：视频号直播间购物袋 → 小程序商品页 → 下单支付（挂载微信官方直播插件）。

2. 耗材周期复购：老客从「我的」进入订单与会员中心，通过分组与积分商城完成复购。

3. 会员权益运营：开卡 → 等级成长 → 会员价与专属券 → 礼品卡 / 储值卡使用。

4. 门店 O2O：定位最近门店 → 门店货架浏览或扫码购 → 门店自提或同城配送。

5. 分销裂变：导购或分销员分享商品与素材 → 好友下单 → 佣金与业绩统计。

6. 积分与任务：签到、打卡与任务中心赚积分 → 积分商城兑换商品或优惠券。

本章提出性能、包体、兼容、合规与稳定性方面的约束与要求。

类别要求
性能高频链路分包预加载（购物车、下单、支付结果、用户中心已配置）；首页依赖远程装修数据，需保证首屏骨架屏与失败兜底，避免白屏
包体管理实测主包 5.06MB、22 个包合计 27.25MB（本地缓存加密态）。需遵守微信官方包体约束（以平台最新规范为准，主包与单个分包均不得超限）；新增功能优先落入既有分包，避免主包持续膨胀
渲染与兼容当前为 webview 渲染 + exparser 组件框架，未启用 Skyline；后续如切换渲染引擎，需评估自定义组件与动效兼容性
隐私合规已声明位置权限（用于计算用户与门店距离），调用 getLocation、chooseLocation、chooseAddress 需在隐私协议中明示并前置授权，按个人信息保护相关法规与微信隐私接口规范留存授权记录
安全支付走微信支付官方通道；会员、积分、佣金等资产类数据需服务端校验；签到、领券、抽奖等可被刷的接口需限频与风控

稳定性下单、支付、退款等关键链路需具备异常兜底与订单状态补偿；直播与视频号引流峰值需评估并发承载

附录：数据来源与拆解方法

1. 采集方式：PC 微信客户端（Weixin 4.x）本地小程序缓存包，路径为 %APPDATA%\Tencent\xwechat\radium\users\<hash>\applet\packages\wx6bc687ff89875e20\61\，含主包 __APP__.wxapkg 及 21 个子包文件，共还原 529 个文件。

2. 解密方法：PC 端小程序包为 V1MMWX 加密格式，密钥由 PBKDF2-SHA1（appid，salt "saltiest"，1000 次迭代，32 字节）派生；前 1023 字节为 AES-256-CBC（IV "the iv: 16 bytes"）解密，其余字节按 appid 倒数第 2 个字符（字符「2」即 0x32）异或还原，随后按 wxapkg 索引结构解包。

3. 数据口径：页面数（452）、分包数（82）、顶部与底部导航、插件、权限声明、预加载规则均直接读取解包后的 app-config.json；包体体积为本地缓存加密文件实际大小，与线上发布包体存在差异。

4. 需运营侧确认项：① 首页实际启用的装修模块及顺序（取决于有赞后台装修配置）；② 模板自带但未确认启用的模块（付费内容 paidcontent、教育 edu、酒店 hotel、社区团购 groupbuying、品酒会 wine-tasting 等）；③ 会员卡、积分商城、分销等模块的当前开启状态。

5. 名称口径：小程序名称「LEXY莱克官方旗舰店」取自小程序运行时网络缓存数据（同源请求参数 app_id=wx6bc687ff89875e20 与 kdt_id=44375018），响应字段实测为 shopName=LEXY莱克官方旗舰店、nameMode=shopName、type=chain；微信分享卡片名简写为「LEXY莱克」，二者指向同一小程序，并非两款不同产品。

6. 版本说明：本次拆解基于线上版本 3.179.7.101（本地缓存包版本 61），页面与模块清单随版本迭代可能变化。
