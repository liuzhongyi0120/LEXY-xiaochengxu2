## 五、更新与维护流程

1. 修改对应的 `source/*.md`（内容层，定稿以此为准）
2. 同步修改对应的 `source/*.html`（排版层，保持章节与编号一致）
3. 用排版稿重新生成 Word 交付版到 `docs/`，文件名带版本号
4. 在 `README.md` 第三节补一行版本记录
5. 提交：`git add -A && git commit -m "docs: V2.2 更新说明" && git push`
