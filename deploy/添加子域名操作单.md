## 三、易名中国实操步骤（照这个点）

> ⚠️ **先别打开错网站**：域名管理后台是 **`www.ename.net`**。
> **`www.ename.cn` 是他们的资讯门户**（域名/商标新闻），打开那里**找不到任何解析入口**，会白折腾。
> 认准 **`.net`** 结尾。

### 路线 A：从域名管理进（推荐）

1. 打开 **<https://www.ename.net/>** → 右上角「**登录**」→ 输账号密码
2. 登录后进「**管理中心**」→「**我的域名**」（域名列表）
3. 在列表里找到 **`lexy.cn`**（如列表很长可用搜索框过滤）
4. 点该域名右侧的「**解析**」链接（会自动跳转到 iidns 解析平台）
5. 在解析记录列表页，点「**添加记录**」
6. 按下表填写 → 点「**保存**」

### 路线 B：用解析专属密码进（不需要主账号，适合 IT 交接）

1. 打开 **<http://www.ename.net/dns>**（易名官方帮助文档给出的解析专属入口）
2. 填域名 `lexy.cn` + **域名管理密码** → 登录
3. 点「**添加记录**」→ 按第四节填 → 「**保存**」

> 两条路线进入的是**同一个解析面板**。路线 B 的价值：IT 不必把主账号密码交出来，
> 只给一个「域名管理密码」就能让你自己加这条记录。

## 四、这条记录填什么（逐格对照）

| 字段 | 填什么 | 说明 |
|---|---|---|
| **记录类型** | **A** | ⚠️ 不是 CNAME、不是 AAAA（IPv6）、不是 URL 转发 |
| **主机记录** | **`mall`** | ⚠️ 只填 `mall` 四个字母 —— **不要**填 `mall.lexy.cn`、不要填 `@`、不要填 `www` |
| **记录值** | **`14.103.50.137`** | ⚠️ 只填 IP 裸值 —— **不要**带 `http://`、不要带端口、不要带斜杠 |
| **TTL** | `600` | 易名默认值，10 分钟 |
| 线路 / 解析线路 | 默认（全网） | 不需要分线路 |

**保存后应当看到这样一条：**

```
记录类型   主机记录   记录值            TTL    状态
A          mall       14.103.50.137     600    正常
```

## 五、四个容易踩的坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | 主机记录填成 `mall.lexy.cn` | 实际生成 `mall.lexy.cn.lexy.cn`，永远不生效 |
| 2 | 记录值带上 `https://` 或 `:443` | 非法值，保存报错或解析失败 |
| 3 | 选了 CNAME / URL 转发 | 微信校验不过（CNAME 链到 IP 也不行）；转发不支持 HTTPS 证书 |
| 4 | 顺手改了 `@` / `www` / `mail` 等已有记录 | **公司官网或企业邮箱会挂** —— 只新增，别动任何已有记录 |

> ⚠️ **一个正常现象**：`.cn` 域名若开过「隐私保护」，易名在使用自家 DNS 做解析时**会自动取消该保护**，你可能收到短信/站内通知。这是易名官方规则，**不是被攻击**，不用紧张。

```

```
✓ 3/3 个可用 DNS 都解析正确

- 如果三个 DNS 里**只有一两个**通了 → 正常，DNS 有传播过程，等 10~30 分钟再跑
- 如果**全都没有记录**（ENODATA）→ 记录没保存成功，或主机记录/类型填错，回第四节核对
- 官方给的生效时间是 **0.5~24 小时**，实测通常 10 分钟内
