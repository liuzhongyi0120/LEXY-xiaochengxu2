## 一、推荐版（177 字，直接复制）

```
本小程序由莱克电气绿能科技（苏州）有限公司运营，为品牌自营商城，仅销售本公司及集团所属品牌的家用电器商品，包括吸尘器、洗地机、除螨仪、净饮机及滤芯耗材、咖啡机、破壁机、空气净化器、加湿器、除湿机、吹风机等，不涉及第三方商家入驻。主要服务：商品展示与查询、在线下单与支付、订单物流查询、优惠券与会员权益、退换货办理及在线客服咨询，并提供品牌与产品资讯展示。
```

**为什么这么写**：主体 + 经营模式（自营）+ 商品范围（具体到品类）+ 服务内容（全流程）+ 主动排除平台属性。
每一个分句都能在代码里对上实证，见第四节。

## 三、填写要点（5 条，逐条对一遍）

| # | 要点 | 说明 |
|---|---|---|
| 1 | **主体名称逐字照抄营业执照** | 最容易被打回的一点。括号的**全角「（）」还是半角「()」**、有没有「（苏州）」、有没有空格 —— 全部与执照一致。备案会与公安/市场监管数据交叉比对 |
| 2 | **必须写明「自营」** | 写了「自营」= 走「商家自营」类目（无需额外资质）；一旦读起来像**多商家入驻平台**，会被要求 **ICP 经营许可证 / EDI 资质**（周期以月计）。推荐版里「不涉及第三方商家入驻」这句是**主动声明**，别删 |
| 3 | **与后台选的服务类目一致** | 服务类目选「**商家自营 → 家用电器**」（食品/医疗器械等才需前置审批）。描述里出现「家用电器」就与类目对上了。**描述与类目互相矛盾是高频驳回原因** |
| 4 | **别写没有的功能** | 本项目**没有**直播、短视频、社交、社区、金融、返利、抽奖、众筹。写进去 = 给自己加审核项甚至加资质要求。反向也成立：**有的别漏**（比如「在线支付」一定要写，否则后续接支付时与备案不符） |
| 5 | **不用极限词** | 「最大 / 第一 / 首选 / 国家级 / 领先」这类广告法禁语一律不出现 |
